# Project: Recipes

This is a simple website built using only HTML. It was created as part of [The Odin Project](https://www.theodinproject.com/) to practice basic HTML skills.

**Live Site:** [secrescence.github.io/odin-recipes](https://secrescence.github.io/odin-recipes/)

## What I Learned

In this project, I learned how to use:

- Headings (`<h1>`, `<h2>`, etc.)
- Paragraphs
- Links to other pages
- Images
- Unordered lists (for ingredients)
- Ordered lists (for steps)

## Features

- A homepage with a title, cover image, and links to recipes
- Three recipe pages:
  - Each has a title, image, description, ingredients list, and step-by-step instructions
  - Includes a link to go back to the homepage

## How to View

1. Download or clone the project files
2. Open `index.html` in your web browser
